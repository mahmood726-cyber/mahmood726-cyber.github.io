Portfolio Overview

The body of work

This portfolio spans 143 projects in evidence synthesis methodology, from pairwise meta-analysis to network comparison, diagnostic test accuracy, health technology assessment, and novel methods like multiverse analysis and topological data analysis. Every project ships with an E156 micro-paper (exactly 156 words, 7 sentences), an interactive HTML companion for reviewers, and open-source code. 113 projects include browser-based interactive apps that run with zero installation.
