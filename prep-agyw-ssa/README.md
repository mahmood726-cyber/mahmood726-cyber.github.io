# PrEP Initiation in AGYW — RapidMeta living evidence dashboard

A single-file, offline-capable HTML meta-analysis dashboard (RapidMeta) for
**pre-exposure prophylaxis (PrEP) initiation among adolescent girls and young
women (AGYW) in sub-Saharan Africa**. The page bundles the extracted study data,
a client-side random-effects meta-analysis engine, a forest plot, and a GRADE
summary-of-findings table — everything runs in the browser with no server.

- **Live:** served as part of the [mahmood726-cyber.github.io](https://mahmood726-cyber.github.io/) Pages site (`/prep-agyw-ssa/`).
- **Contents:** `index.html` is fully self-contained.
- **Scope/limits:** estimates are computed from the data embedded in the page and
  may shift as additional studies report; see the in-app methods and limitations
  sections for the analytic detail.
