## Methods Atlases

- [**PI Atlas**](https://github.com/mahmood726-cyber/pi-atlas) — Year-long prediction-interval calibration study on 595 Pairwise70 reviews; pre-registration v1.0.0 tagged. *(in-review)* · [source](https://github.com/mahmood726-cyber/pi-atlas)
- [**Reproduction-Floor Atlas**](https://mahmood726-cyber.github.io/repro-floor-atlas/) — 7,545 MAs across 595 Cochrane reviews; 14.3% non-reproducible at |Δ|>0.005. *(preprint)* · [source](https://github.com/mahmood726-cyber/repro-floor-atlas)
- [**Responder-Floor Atlas**](https://mahmood726-cyber.github.io/responder-floor-atlas/) — Empirical implied MIDs exceed canonical by 1.28× to 3.81× (clustered bootstrap 95% CI; 2013 trial-arms). *(preprint)* · [source](https://github.com/mahmood726-cyber/responder-floor-atlas)
- [**cochrane-modern-re**](https://mahmood726-cyber.github.io/cochrane-modern-re/) — DL→REML+HKSJ+PI flip-rate analysis on 6,386 Pairwise70 MAs; Tier-1 significance flip 8.2%. *(preprint)* · [source](https://github.com/mahmood726-cyber/cochrane-modern-re)
- [**ImpossibleMA**](https://mahmood726-cyber.github.io/impossible-ma/) — Possibility-envelope primitive for k=1, missing-SE, and adversarial pooling cases. *(shipped)* · [source](https://github.com/mahmood726-cyber/impossible-ma)
